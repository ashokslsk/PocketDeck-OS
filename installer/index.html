Steps

  1. Charge the reader and turn it on. Wake it so the screen shows Home or a book. A sleeping reader isn't visible over USB.
  2. Connect it with a USB-C data cable. Some cables only charge. If nothing shows up in step 3, try another cable or port.
  3. Press Connect & install and pick the reader. It's listed as USB JTAG/serial debug unit (on macOS the port looks like cu.usbmodem…).
  4. Choose Install PocketDeck-OS, then confirm. Keep the cable connected and this tab open until it says the install is done (about 1–2 minutes).
  5. Restart the reader. It usually restarts by itself. If the screen doesn't change, press the power button. The PocketDeck-OS boot screen appears.

What's kept

  • Your books, reading progress, bookmarks and settings are on the SD card and stay where they are.
  • The install replaces the firmware only. It works from stock Xteink firmware, CrossInk or an earlier PocketDeck-OS.
  • For sample quotes, habits and wallpapers, copy the sd-sample/tools folder from the repository to the SD card.

Troubleshooting

The reader isn't in the list

Wake the reader, unplug and reconnect the cable, then press Connect & install again. Use a data cable and plug straight into the computer rather than through a hub.

"Failed to initialize" or the port is busy

Another app has the port open. Close serial monitors (PlatformIO, Arduino IDE, screen) and other tabs using the reader, reconnect the cable, and try again.

It stopped halfway

Nothing is lost: reconnect and install again. The reader starts the bootloader before the app, so a fresh install always gets through.

I'd rather not use USB

If the reader already runs CrossInk or PocketDeck-OS, download pocketdeck-os-x3.bin, copy it to the SD card, and open Settings › System › SD Card Firmware Update.

PocketDeck-OS is open source, built on CrossInk and CrossPoint. Source on GitHub.
