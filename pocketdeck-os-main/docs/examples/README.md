# Examples

- `templates/tools/` — ready-to-copy starting points for the SD card:
  `flashcards/my_subject.json`, `knowledge/My_Topic.json`, `quotes.txt`,
  `habits/habits.txt` and `medicine/courses.txt`. Copy a file into the same
  folder under `/tools` on the card, then edit it. See
  [INSTALLATION_GUIDE.md](../../INSTALLATION_GUIDE.md#3-the-content-routine).
- `stats-export/` — a real **Tools > Stats & export** result from the X3
  simulator with demo data, so you can see every JSON file and field before
  exporting from your own device.
